QMST Tape & Ledger

The live dashboard is served at http://127.0.0.1:9876/ (not a static file).

Start or refresh the server from the repo root:

python3 scripts/serve_dashboard.py --rebuild --portfolio-amount 100000 --open

After each analyze_top200_stocks_enhanced.py run, the HTML rebuilds automatically. If the browser tab looks stale:

kill $(lsof -ti :9876) 2>/dev/null
python3 scripts/serve_dashboard.py --open

Then hard-refresh Chrome: Cmd+Shift+R.
