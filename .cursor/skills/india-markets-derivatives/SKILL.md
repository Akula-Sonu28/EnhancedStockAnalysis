# Derivatives Desk — Research Only

**Stock_Analysis does not compute F&O chains, OI, or margin.** This desk provides structured **research memos** only.

## When to use

- User asks about Nifty/Bank Nifty options, hedging a stock portfolio, or F&O ban/MWPL
- Hedging **equity picks from pipeline** — read equity actions from report first, then propose hedge overlay

## Workflow

1. Confirm: research/education vs expecting pipeline data (pipeline has no F&O).
2. For hedging: load equity book from **Portfolio Allocation** + holdings.
3. Use external NSE data if user needs live OI — cite NSE F&O snapshot; never invent.
4. Include STT/expiry/weeklies context (India-specific).

## Report template

```markdown
# F&O Research Memo

**Note:** Not generated by Stock_Analysis pipeline.

## Equity book to hedge (from repo if applicable)
| Symbol | Action | Weight |

## Proposed structure
[Legs, max loss, breakeven — qualitative unless live data provided]

## Risks
Gap, assignment, margin, event (RBI/results)

**Disclaimer:** Not investment advice. F&O involves substantial risk.
```
