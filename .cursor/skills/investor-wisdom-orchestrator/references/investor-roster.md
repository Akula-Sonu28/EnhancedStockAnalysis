# Famous Investors — Master Roster

Use this table to route questions to the right skill. For “compare how X and Y would view this stock,” load both skills via `investor-wisdom-orchestrator`.

## Global — Value & quality

| Investor | Skill folder | Style | Typical hold |
|----------|--------------|-------|--------------|
| Benjamin Graham | `investor-benjamin-graham` | Deep value, margin of safety, net-net | Months–years (cigar butts) |
| Warren Buffett | `investor-warren-buffett` | Quality compounders, moat, owner earnings | Very long (decades) |
| Charlie Munger | `investor-charlie-munger` | Quality at fair price, mental models | Very long |
| Joel Greenblatt | `investor-joel-greenblatt` | Magic formula, special situations | 1–3 years |

## Global — Growth

| Investor | Skill folder | Style | Typical hold |

## Routing quick guide

| User question | Primary skill(s) |
|---------------|------------------|
| “Is this cheap vs assets?” | Graham, Greenblatt |
| “Is this a 20-year compounder?” | Buffett, Munger, Damani |
| “Fast grower at reasonable PE?” | Lynch, Fisher, Kedia |
| “Where are we in the cycle?” | Marks, Dalio |
| “Macro bet on rates/INR?” | Dalio, Druckenmiller, Soros |
| “Disruptive tech theme?” | Wood (with skepticism skill optional) |
| “Indian midcap multibagger?” | Jhunjhunwala, Kedia, Agrawal |
| “Compare Buffett vs Lynch on ITC” | Orchestrator → both skills |
